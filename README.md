# 🛒 Retail Sales Analytics Dashboard

A professional Retail Sales Analytics Dashboard built using **Databricks, PySpark, Delta Lake, SQL, and Power BI** to analyze retail sales performance, customer behavior, product revenue, order trends, and data quality insights.

---

## 📌 Project Overview

This project demonstrates an end-to-end retail analytics workflow using a modern data engineering and business intelligence stack.

The dashboard helps stakeholders monitor:

- Revenue performance
- Order trends
- Customer distribution
- Top-selling products
- Order status analysis
- Data quality monitoring

The project follows a Medallion Architecture approach for scalable data processing and analytics.

---

| Technology | Purpose |

## 📊 Dashboard Features

### Executive Dashboard KPIs

- 💰 Total Revenue
- 📦 Total Orders
- 👥 Total Customers
- 🛡️ Data Quality Issues

### Business Insights

- Revenue by Category
- Top Products by Revenue
- Order Status Distribution
- Customer Analysis by State
- Data Quality Check Report

### Interactive Filters

Users can dynamically filter data using:

- Category Filter
- Order Status Filter
- State Filter

---

## 🏗️ Data Architecture

This project follows the **Medallion Architecture**:

### 🥉 Bronze Layer
Raw ingested retail sales data.

### 🥈 Silver Layer
Cleaned and transformed datasets.

### 🥇 Gold Layer
Business-ready aggregated datasets for reporting and analytics.
